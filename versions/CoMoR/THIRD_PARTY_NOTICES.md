# Third-party source

`upstream_adapter/MSE-ChatGLM3-6B/` contains the configuration, data loader,
metrics, utilities and ChatGLM source files required by this experiment's
runtime or source-provenance checks. They were copied from the local checkout
of `AZYoung233/MSE-Adapter` at commit
`e0617fec510b2f2c4539e7f8b000efb3dbd98740`.
Its [license](upstream_adapter/MSE-ChatGLM3-6B/LICENSE) and existing file notices
are preserved. Exact file hashes appear in `provenance/source_snapshot.json`.

The router's multi-scale projector is derived from the MSE-Adapter design.
This archive does not contain pretrained language-model weights or datasets.
